# 엄마의 삼단정리

`엄마의 삼단정리`는 제한 시간 안에 블록을 정리해 점수를 올리는 2D 액션 퍼즐 게임입니다.\n
여러 줄에 쌓이는 블록 중 맨 앞 블록을 골라 다른 줄로 옮기고, 같은 색 블록 3개를 연속으로 맞춰 제거하는 방식으로 진행됩니다.

## 게임 소개

플레이어는 계속 쌓이는 블록을 빠르게 정리하며 최대한 높은 점수를 노립니다.
블록을 맞출 때마다 점수와 콤보가 오르고 남은 시간이 조금씩 늘어나기 때문에, 끊기지 않고 연속으로 정리하는 판단력이 중요합니다.

게임이 진행될수록 등장하는 블록 종류가 늘어나고 난이도가 올라갑니다. 
일정 횟수 이상 블록을 맞추면 피버 상태가 발동해 게임 속도가 빨라지고, 슈퍼 피버에서는 화면의 블록이 크게 정리된 뒤 제한된 색상의 블록이 다시 생성되어 더 큰 콤보를 노릴 수 있습니다. 
특수 폭탄 블록은 선택 후 다른 줄을 클릭하면 각 줄의 블록을 여러개 제거합니다.

블록이 한 줄에 너무 많이 쌓이거나 제한 시간이 모두 지나면 게임이 종료됩니다.

## 조작법

| 조작 | 설명 |
| --- | --- |
| 마우스 왼쪽 클릭 | 줄을 선택합니다. |
| 블록이 있는 줄 클릭 | 해당 줄의 맨 앞 블록을 선택합니다. |
| 다른 줄 클릭 | 선택한 블록을 해당 줄의 맨 앞 위치로 옮깁니다. |
| 같은 줄 다시 클릭 | 선택한 블록을 취소합니다. |
| 게임 오버 후 아무 키 입력 | 게임을 다시 시작합니다. |
